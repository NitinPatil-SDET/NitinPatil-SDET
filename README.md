## How I Work

1. **Discover** the user's actual pain point and success criteria.
2. **Map** the workflow, dependencies, constraints, and failure modes.
3. **Design** the simplest useful architecture and define trade-offs.
4. **Build** a working vertical slice before expanding scope.
5. **Validate** with tests, users, and realistic edge cases.
6. **Deploy** with monitoring, logs, documentation, and rollback thinking.
7. **Measure** adoption, accuracy, time saved, and operational impact.
8. **Iterate** using evidence instead of assumptions.
